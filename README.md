# SQL Patterns in 20 Days 🚀

This repository documents my **20-day structured SQL practice plan**, focused on mastering  
**interview-level MySQL queries using pattern-based learning**.

Each SQL pattern is practiced for **2 days** to ensure **deep understanding**, not memorization.

---

## 🎯 Goal

To become **confident and interview-ready** in SQL by mastering:
- Query logic
- Pattern recognition
- Real-world interview questions

By the end of this plan, I aim to comfortably solve **90%+ SQL interview questions**.


---

## 📅 20-Day Learning Plan

|    Days   |              Topic               |
|-----------|----------------------------------|
| Day 1–2   | SELECT & WHERE                   |
| Day 3–4   | ORDER BY & LIMIT                 |
| Day 5–6   | Aggregate Functions              |
| Day 7–8   | GROUP BY                         |
| Day 9–10  | HAVING                           |
| Day 11–12 | JOINS (INNER, LEFT, RIGHT, SELF) |
| Day 13–14 | SUBQUERIES                       |
| Day 15–16 | CASE WHEN                        |
| Day 17–18 | DATE FUNCTIONS                   |
| Day 19–20 | Mixed Interview-Level Queries    |

---

## 🛠 Database Setup

This repository uses **MySQL**.

### Steps to Run Locally:
1. Run `schema.sql` to create the database and tables
2. Execute SQL files from the respective day folders
